# The Friendly Ghost Career Counselor - Kiro Steering Rules

1. **Strict Data Contracts:** All LLM outputs MUST be strictly typed and validated using Zod via `GhostResponseSchema` (and `CustomTarotCardSchema` for AI-synthesized Tarot cards) and sanitized with `sanitizeNoEmDashes` before reaching UI state.
2. **Global Context:** Do not hardcode localized regional data (like RM or specific local colleges). The counseling architecture must support international users, dynamically adjusting cost-of-living and salary advice for global contexts.
3. **Resilient Error Handling & Zero-Config Fallback:** All external AI calls must be wrapped in `try/catch` blocks with a 3-layer cascade (optional Gemini `gemini-2.0-flash` → zero-key Free AI → deterministic stage-aware offline engine) so the app never crashes and remains testable out of the box without an API key.
4. **Costume Contest Visual System:** Use Tailwind CSS paired with custom dark-velvet and gothic-neon utilities. Every spooky visual element (volumetric mist, costume switcher, aura rings, tarot cards) must directly reinforce counseling usability and readability.
5. **Psychometric Integrity in 3D Assessment:** Never expose the 4 core dimension labels (`Maker`, `Architect`, `Catalyst`, `Visionary`) prior to assessment completion. Always rotate portal colors and compass directions across scenarios so players choose based on instinct rather than color or directional habit.
6. **Privacy-First On-Device Vision:** Webcam facial landmark detection (eyebrows, mouth, eye contact, head-turn yaw, and stress gauge) must execute 100% client-side in the browser via bundled WebAssembly (`public/mediapipe`, `public/wasm`, `public/models`)—no video frames or biometric scores may be transmitted to external AI APIs.
7. **Hybrid Tarot Arcana & Chat-Aligned Filtering:** Keep all 14 classic Tarot cards (`CAREER_ARCANA_CATALOG`) intact in `src/services/soulDossierEngine.js`. When a user discusses a career outside the 14 cards, synthesize a Zod-validated custom Tarot card (`ARCANA XV+`) via Cloud AI (when consented) or local offline fallback. Whenever any card carries the `💬 Chat Aligned` badge, display only `💬 Chat Aligned` cards so unrelated filler cards stay hidden.
8. **AI Consent, Transparency & Secure Static Auth:** Enforce pre-flight Cloud vs. Offline AI consent (`AiConsentModal.jsx`), keep the **Spectral Note** AI disclaimer visible in Chat and Soul Dossier exports, avoid logging guest PII in URLs/analytics, and hash private `JUDGE_PASSCODE` / `DEV_PASSCODE` values with salted SHA-256 at build time in `vite.config.js` so plaintext passcodes never enter GitHub or client bundles.
9. **No-Reframing Safety Boundary:** Keep `### SAFETY & CONTENT BOUNDARIES (HIGHEST PRIORITY)` at the top of the system prompt and enforce deterministic `isHarmfulContentBlocked()` pre-filtering before trait extraction or Tarot generation so violence, animal cruelty, sexually explicit/porn/fetish content, illegal acts, and hate speech are immediately refused neutrally without reframing into career paths (while self-harm/abuse continues returning the `988` Crisis Lifeline override).
